# learning-notes

人工智能专业学习仓库 —— C语言 / Python / 算法 / 笔记 持续积累。

## 目录结构

| 目录 | 用途 |
|---|---|
| `01-C语言/` | C 课程作业、练习、小项目 |
| `02-Python/` | Python 练习、脚本、数据分析 |
| `03-算法与数据结构/` | LeetCode/PTA 题解、数据结构实现 |
| `04-AI-机器学习/` | 机器学习、深度学习代码与实验 |
| `05-笔记/` | 课堂笔记、读书笔记、Markdown 文档 |
| `06-Git练习/` | Git 操作练习（分支、合并、冲突处理） |

## 使用约定

- 每学一个知识点，就在对应目录建一个文件夹，附 `README.md` 说明
- 每天 commit 一次，提交信息格式：`类型: 简述`（如 `feat: 第一个C程序 hello world`）
- 提交类型：`feat` 新功能/新练习、`fix` 修正、`docs` 文档、`note` 笔记
