# 06-Git练习

Git 操作练习区，随便折腾，搞坏了也无所谓。

## 练习清单
- [ ] `git init` / `git add` / `git commit`
- [ ] `git status` / `git log` / `git diff`
- [ ] 创建分支 `git branch` 并合并 `git merge`
- [ ] 人为制造冲突并解决
- [ ] `git clone` 别人的仓库
- [ ] 关联 GitHub 并 `git push`
- [ ] 误删恢复：`git checkout` / `git stash`
